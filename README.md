# Portfólio Dev

Site estático em React + Vite, reproduzindo a direção visual fornecida.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão estática: `npm run build`. Para visualizá-la: `npm run preview`.

## Editar conteúdo

Todos os textos, links, habilidades, projetos e experiências estão centralizados em `src/data/portfolio.ts`. As imagens de projetos e fundos ficam em `assets/` e são servidas diretamente pelo Vite.
